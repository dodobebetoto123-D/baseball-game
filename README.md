# Diamond Dynasty

Diamond Dynasty is an original, responsive baseball management game prototype built for desktop browsers with Vite, React, and TypeScript. Manage the Fireflies, tune the starting lineup, open club card packs, and play a lightweight live match simulation.

## Setup

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

## Scripts

- `npm run dev` — start the Vite development server
- `npm run typecheck` — run the TypeScript project check
- `npm run build` — typecheck and create a production build
- `npm run preview` — preview the production build locally

All visual assets are original CSS treatments, emoji, and interface shapes; no external game or team artwork is used.
